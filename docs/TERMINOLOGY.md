# Controlled terminology

| Term | Project meaning | Avoid saying |
|---|---|---|
| Public-use data | Data made available for broad use under repository terms. | Automatically anonymous or risk-free data. |
| Direct identifier | Identifier-like or operational field excluded from release candidates by configuration. | Proof that a person is identifiable. |
| Quasi-identifier | Context-dependent attribute that can contribute to singling out in combination. | A universally identifying field. |
| Equivalence class | Records sharing normalized values on a stated QID set. | A group of the same real person. |
| Sample singleton | A record whose observed QID tuple occurs once in the deposited sample. | Re-identified person. |
| Linkability signal | Structural warning under an auxiliary-knowledge scenario. | Re-identification probability. |
| Attribute disclosure | Learning a sensitive property from a class or linkage. | Identity disclosure; the concepts differ. |
| Core scenario | Pre-specified ordinary auxiliary-knowledge QID set. | The true attacker knowledge. |
| Extended scenario | Pre-specified stronger auxiliary-knowledge QID set. | Worst case in all possible worlds. |
| Coarse scenario | Reduced QID set used to study minimization. | Proven optimal release. |
| Restricted review | ASP recommendation for higher-governance review. | Legal prohibition or breach finding. |
| Remediate before release | ASP recommendation to modify fields/scenario and reassess. | Automatic authorization after one change. |
| Public candidate after documented review | No configured high-priority rule fired. | Safe to publish. |
| Semantic status | Evidence level supporting a variable definition. | Data-quality score or truth probability. |
| Protocol paper | Planned study with methods and evaluation defined but no results. | Completed empirical study. |
